FOR YOUR GITHUB ORGANIZATION
Upload assets/github-avatar.png as the organization picture (512 × 512 PNG).
The 1024px master is assets/github-avatar-1024.png.
Use assets/github-header.svg in the organization profile README.
The local profile/README.md already references this banner.
These changes have been prepared locally; no GitHub settings were changed.

LOGOS
assets/mark-light.svg: warm white symbol on transparent background.
assets/mark-dark.svg: dark symbol on transparent background.
assets/mark-black.svg: pure black for one-color reproduction.
assets/mark-violet.svg: violet symbol for dark backgrounds.
assets/lockup-light.svg and lockup-dark.svg: horizontal name + symbol.
SVGs are scalable; the wordmarks contain outlined lettering.
PNG versions are included for applications that do not accept SVG.

OTHER GRAPHICS
assets/github-avatar-light.png and github-avatar-violet.png: alternate avatars.
assets/social-card.png: 1280 × 640 organization social preview.
assets/identity-board.png: concise overview of the identity.
assets/size-checks.png: actual-size square and circular avatar checks.

TYPOGRAPHY
Space Grotesk Medium 500: brand name and headings.
Inter Regular 400 / Medium 500: interfaces and prose.
JetBrains Mono Regular 400: code, versions, and small labels.
Font binaries and their OFL licenses are in fonts/.
TTF files are for desktop design tools. WOFF2 files are for the web.
GitHub README body text uses GitHub's own typography.

REUSE
Use tokens.css or tokens.json to carry the identity into future interfaces.
Keep the symbol's proportions and existing padding. Avoid shadows, gradients,
extra stars, or splitting the arms into different colors.
Use a 48px or larger avatar container in layouts you control. Smaller GitHub
placements will reduce automatically; the included size check shows that tradeoff.

SOURCE
source/galaxy-master.svg contains the authoritative logo silhouette, traced
directly from the approved original to preserve both spiral arms.
source/build.py places that master in every asset and runs the export process.
Requires Python 3.11+, fonttools[woff], and rsvg-convert.
Run: python brand/source/build.py
source/concept.png is the approved built-in imagegen reference; use the
production SVG and PNG files for publishing.
source/design-brief.json records the generation prompts and design sources.

The Vorssaint reference artwork is not included in this kit.
