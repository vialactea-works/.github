A constellation of tools for building, organizing, and navigating software systems.

| Project | Description |
| --- | --- |
| [Pleiades](https://github.com/vialactea-works/pleiades) | A knowledge and content system for connected information. |

## The idea

Vialactea Works develops focused tools that help software projects
understand their surroundings, follow a reliable path, and evolve
with intention.

Each project has its own purpose. Together, they form a small working
system for knowledge, engineering, navigation, and automation.

## Status

These projects are actively evolving. Documentation and contribution
guidance will be added as each project takes shape.
